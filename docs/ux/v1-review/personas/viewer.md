# Viewer: read work across the spaces you can access

A Viewer account is read-only. It is useful for people who need visibility without creating tasks, commenting or requesting agent work.

## Find visible work

1. Log in. Viewers land on Overview.
2. Use Overview to find work needing attention, active work and other visible tasks.
3. Select a space in the sidebar to use its board/table, search and filters.
4. Open a task to read its description, current situation, owner/reviewers and conversation. Use Research, Plan and Code to inspect the available results.

[Viewer Overview](../images/viewer-overview.png) · [Viewer space](../images/viewer-space.png) · [Viewer task](../images/viewer-task.png)

You can see open spaces and private spaces you belong to. If a space is absent or a shared link cannot be opened, ask an admin or maintainer whether you should have access. A link does not grant permission by itself.

## Interpret progress

Read the latest thread entry together with the document. Research describes understanding; a plan describes intended work; Code describes implementation/repository progress. A completed agent turn does not prove delivery. An empty artifact means that artifact is unavailable, not that you should ask the agent yourself.

The current viewer interface has no create-task, composer, agent-request or Watch control. If you need to give feedback, contact the task owner through your team’s established channel or ask an admin whether contributor access is appropriate. Task owner names are shown under People.

Open Settings → Notifications for the channels the workspace has configured. Current copy mentions Home, but Viewer navigation starts at Overview. Do not expect personal task participation controls from this role.

## Current limitations

Situation counts and labels can be misleading in this build; inspect the artifact and latest messages when you need certainty. Empty artifact copy can instruct you to ask/write even though you cannot. Historical-version links show current content rather than the selected revision.
