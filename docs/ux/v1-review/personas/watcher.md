# Watcher / stakeholder: follow progress and contribute context

Watching is a task relationship. Your workspace role still controls your access. A member who watches a task is a contributor, not a read-only viewer.

## Follow a task

1. Open the task from its space, Overview, or a shared task link.
2. Read the desired outcome, current situation and People to understand the owner and reviewers. What owner, reviewer and watcher mean explains each relationship.
3. Under People → Watchers, choose Watch. Your name appears among the watchers; the control becomes Stop watching.
4. Use Home to follow your tasks and new updates. A row's number badge counts new messages; the sidebar Home badge counts things that need you. Open a task to read its latest turn and available Research, Plan or Code.

## Understand what changed

Read the latest human/agent message and artifact together. Each agent turn starts with what it set out to do and a result line, such as “Wrote the research.”; Show what it said opens the full reply. A question means a decision is still needed. Research or a plan is useful progress, but not proof that code shipped. A failure means the owner/admin may need to act; the failure card says who can fix it. Code/PR information describes repository progress; verify a merged change before communicating delivery.

Home’s attention requests are separate from task status. Acknowledge mention stops a mention being your move and leaves the task unchanged. Finishing the task itself uses Actions → Finish task and depends on your capabilities.

## Contribute without taking ownership

Write a message when you have useful scope, wording or acceptance context. Type @ and select the person you want to reach, then Post. Mention an agent if you intend to request its work; an ordinary human message does not itself run the agent. Requests made while the agent is working wait for the current turn.

Watching does not make you the owner or grant pause/takeover privileges. Members/guest task participants can nevertheless ask for code under the current policy, so use those actions deliberately and coordinate with the owner.

Open Your settings → Notifications to see current email/Slack availability. Delivery depends on the workspace connection; following a task is not a guarantee that every event becomes an email. Choose Stop watching when the task no longer concerns you. That removes the watcher relationship, not your other roles on the task.
